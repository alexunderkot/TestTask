# Калькулятор с прямой польской нотацией

## Описание
Калькулятор, реализующий синтаксический анализ математических выражений и вычисление 
с использованием прямой польской нотации (префиксной записи).

## Особенности
- Поддержка операций: +, -, *, /
- Поддержка скобок: (, )
- Работа с целыми и вещественными числами
- Преобразование в прямую польскую нотацию
- Обработка ошибок (деление на ноль, несогласованные скобки)
- Тестовый режим

## Сборка и запуск

### С Docker
```bash
# Сборка образа
docker build -t polish-calculator -f .devcontainer/Dockerfile .
# Запуск интерактивного режима
docker run -it --rm polish-calculator
