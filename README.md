Разработка в Dev Container (VSCode)

Для Linux
1. Установите расширение Remote - Containers
2. Нажмите F1 → выберите "Reopen in Container"
3. Дождитесь сборки контейнера
4. Нажмите F5 для запуска отладки

Для Windows
1. Откройте консоль в желаемой папке.
2. Скопируйте все файлы туда
3. Зайдите в корневую папку через консоль
4. Введите команду docker build -t echo-server .
5. Запустите сервер на доступном порте, например: docker run -p 8080:8080 echo-server
6. Подключитесь по ссылке (для примера: http://localhost:8080)
